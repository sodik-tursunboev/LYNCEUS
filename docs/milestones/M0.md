# M0: Foundation

**Goal:** a solid base before any detection logic exists: repo, contracts, database, a labelled seed corpus and an eval harness that runs end to end.
**Rule:** no real detection rules in this milestone. Stub engine only. Tests and eval come first.

This file is the M0 plan. Review it, flag problems, then proceed on approval.

**Status (2026-11-04): NOT complete.** Built and verified locally except the items marked open below. See "Approved amendments" for what changed from this plan and `docs/KNOWN_LIMITATIONS.md` for the full list.

## Approved amendments (2026-11-04)

Agreed after review; they override the text above where they differ.

1. **Project location:** `C:\mirage`, own git repo. Local commits only; nothing is pushed anywhere without explicit approval.
2. **Task runner:** stdlib `tasks.py` (`python tasks.py <task>`), no install needed. ADR-003.
3. **Dependencies** (purpose recorded in ADR-004). Runtime: fastapi, uvicorn, pydantic, pydantic-settings, sqlalchemy, alembic, psycopg. Dev: pytest, httpx, ruff, mypy, detect-secrets. *(`pre-commit` was dropped during the work, see amendment 15.)* Logging uses stdlib `logging` with a redaction filter; no structlog.
4. **Scoring (ADR-005):** the headline recall counts UNKNOWN on a positive sample as a miss. Recall over answered samples is reported alongside it. ERROR is a separate rate, never BENIGN.
5. **SSRF inputs** live in `tests/adversarial/`, not in the scored corpus.
6. **Manifest** gains a `split` field (`dev` | `holdout`) so M1 cannot tune on every sample.
7. **Seed hosts** use only unregisterable names: `.test`, `.invalid`, `.example`, and RFC 5737 addresses (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`).
8. **"UNKNOWN never maps to BENIGN"** is tested through a pure `resolve_state(provider_results)` in contracts, not by enum inspection alone.
9. **Log redaction** covers secret-looking keys and URL query strings and userinfo. URLs are logged as host plus hash, never in full.
10. **Evidence encryption at rest:** M0 only separates evidence payloads into their own table (`ciphertext`, `key_id`). Encryption itself lands in M1, with a fourth draft ADR on key management (DPAPI vs env key). *(ADR-007.)*
11. **Initial migration** may be edited in place until M3 (v0.1); nothing is deployed before then.
12. **CI** also runs the secret scan. The eval smoke gate is "harness exits 0 and writes a schema-valid report", not a metric threshold. CI runs on Python 3.12; local development is on 3.14.
13. **Order of work:** contracts, corpus and eval, API and logging, lint and CI, database last (Docker Desktop is not installed and needs separate approval).
14. **`docs/SPEC.md`** was supplied by the owner and saved verbatim (never reconstructed). Docs were reconciled with it on 2026-11-04.
15. **Hooks (discovered during the work):** the pre-commit framework cannot run on the development machine (Git for Windows' `sh` cannot fork), so hooks are a versioned `.githooks/pre-commit` calling `tasks.py`, and the `pre-commit` package was removed. ADR-003.
