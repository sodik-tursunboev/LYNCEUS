# R1: Independent security review

**Status (2026-11-06): done; fixes verified; some findings are documented rather than fixed (listed below).** You asked for it when I offered it as the next step. The code had only ever been read by the AI that wrote it.

**Method.** Two reviewers with no knowledge of my reasoning, each read-only, each told to find real vulnerabilities and rule violations and to prove them where cheap: one for the Python side (API, URL checks, sandbox, mail and document parsing, intelligence, mailbox clients, response engine), one for the Windows side (agent, quarantine, native host, extension, console, deploy scripts). I did not take any finding on trust: each was checked against the code or reproduced before a fix, and each fix has a test that fails without it. The riskiest fixes were then **mutation-checked**: the fix was broken on purpose and a test had to fail. That was done for the mail sync and the HTML scanner (9 breaks) and for every C# fix (16 breaks); all were caught, and breaks that did not even compile were redone. The other Python fixes (health proof, rate lane, log redaction, egress names, OAuth listener, response state machine, sandbox, deploy scripts) have tests that exercise the behaviour directly (the sandbox test was seen to fail before the fix); a second mutation pass over them is recorded in the results block below.

**Result.** 32 findings were reported; 3 were found by both reviewers, so 29 are distinct: 4 High, 4 Medium, 17 Low, 4 Info. 20 are fixed with tests, 4 partly fixed, 5 documented as limits.

## Reviewed and found sound (their words, summarised)
Named-pipe and native-host framing and validation; loopback-only HTTP client with no proxy or redirects; the file pipeline's handling of paths, links and placeholders; strict validation of everything the sandbox returns; the sandbox launcher's handle and job handling; SSRF address checks (about 55 addresses tried); bearer-token comparison, Host check, no CORS, console CSP and static-file traversal; the mailbox egress guard and scope checks; no raw SQL, `eval`, `pickle` or `shell=True` anywhere in the core; the install script's use of `npm ci --ignore-scripts`.

## Not reviewed
Native parser internals (qpdf, Pillow, OpenCV, libxml2) and any sandbox escape; live Google, Microsoft and browser behaviour; a multi-user machine; CI; the installed copy under `%LOCALAPPDATA%\Programs\Mirage`.
